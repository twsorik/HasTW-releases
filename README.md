# HasTW

Видеоплеер для Windows, который умеет играть **две аудиодорожки одновременно** с отдельной громкостью.

## Скачать
Откройте [последний выпуск](../../releases/latest) и скачайте **HasTW-Setup.exe**.
Права администратора не нужны. Если Windows покажет «Система Windows защитила ваш компьютер» —
«Подробнее» → «Выполнить в любом случае» (у программы нет платной цифровой подписи).

Без установки — **HasTW-portable.zip**: распакуйте и запускайте `HasTW.exe`.

## Обновления
HasTW сам сообщает о новой версии и обновляется одной кнопкой — настройки и история сохраняются.
